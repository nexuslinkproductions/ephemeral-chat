One session. Nothing kept.

Peer to peer and encrypted at both layers. Messages and files live only in this tab. Close it and they are gone. Both people need to be online at the same time. The session wipes itself after 30 minutes without activity.

Before you type anything, compare the 60 digit safety number with the other person over a call or in person. The number proves the two apps derived the same keys, not who the other person is. A code that travels over a writable channel can be swapped, and only that comparison catches it.

The invite code carries your public IP address and port, and default mode does not hide who is talking to whom. The traffic is identifiable as WebRTC and can be blocked on many networks. A malicious browser extension can read this session and the app cannot stop it. A public STUN server is used only to find a direct route. Nothing is written to local storage, IndexedDB, or cookies.
